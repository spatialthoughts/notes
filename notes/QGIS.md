## 2026

- [NextGIS Web Community Edition](https://nextgis.com/blog/nextgis-web-community-edition/): Free, open-source Docker image for deploying a full Web GIS platform on your own infrastructure — acts as a spatial data hub for managing and publishing geodata, and as a QGIS teamspace for multi-user collaborative editing with version control and sync. [Webinar](https://www.youtube.com/watch?v=rELUdu8HwJg) Related: [[Tools]], [[Data]]. Keywords: QGIS, Docker, open-source, Web GIS, self-hosted, spatial data, collaboration

- [QGIS India User Group](https://in.qgis.org/): Community of QGIS users passionate about open-source geospatial technology, dedicated to promoting QGIS adoption, facilitating knowledge exchange, and organizing local learning events across India. Related: [[Tools]]. Keywords: QGIS, India, community, open-source, geospatial, user group

## 2025

- [Aurora Map QGIS](https://hkuril.com/html/en/articles/aurora_maps.html): Tutorial on creating stunning aurora borealis style maps using QGIS. Related: [[Cartography]]. Keywords: QGIS, cartography, maps, visualization, aurora

- [QGIS Color Extraction Model](https://github.com/StaridasGeography/QGIS-Color-Extraction-Model): A QGIS tool that converts RGB rasters into color clusters based on HSV color space, generating classified rasters and color palettes with RGB, HSV, CMYK, and HEX values. Related: [[Cartography]], [[Remote_Sensing]], [[Machine_Learning]]. Keywords: QGIS, color, raster, HSV, palette, classification

- [QGIS Plugins for Topological Data Editing](https://github.com/nlsfi): FOSS4G 2025 presentation on QGIS plugins and tools for topological data editing from Finnish NLS. Related: [[CNG]], [[Data]], [[Tools]]. Keywords: QGIS, topology, editing, plugins, FOSS4G
