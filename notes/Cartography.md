# Cartography

**Summary**: Notes on maps, mapmaking, and cartographic design tools.
**Last updated**: 2026-09-03

---

## 2026

- [How We Built the World's Prettiest Auto-Generated Transit Maps](https://blog.transitapp.com/how-we-built-the-worlds-prettiest-auto-generated-transit-maps-12d0c6fa502f/): Transit's approach to auto-generating attractive transit maps by processing routes in pixel space — drawing lines thickly then skeletonizing them to find shared segments, using integer linear programming to minimize crossings, and rounding with circular arcs. Keywords: transit maps, auto-generation, skeletonization, pixel space, ILP, map design

## 2025

- [Weaving Space: Multivariate Maps](https://dosull.github.io/weavingspace/presentations/FOSS4G-Nov-2025/#/title-slide): FOSS4G 2025 presentation introducing `weavingspace`, a Python module using tiling and weaving techniques to combine multiple choropleth maps into single multivariate visualizations. Related: [[Python]], [[CNG]]. Keywords: cartography, multivariate, choropleth, Python, visualization, FOSS4G

- [Lonboard Visualization - Climate Projection](https://github.com/samarchie/foss4g-auckland-2025-lonboard/): FOSS4G Auckland 2025 notebooks demonstrating high-performance geospatial visualization with Lonboard using GPU-accelerated WebGL rendering. Related: [[Web_Mapping]], [[CNG]], [[Python]]. Keywords: cartography, visualization, Lonboard, WebGL, GPU, FOSS4G, Python

## 2024

- [Map Warper - Online Georeferencer](https://mapwarper.net/): Free, open-source online tool for georeferencing historical maps and overlaying them on modern maps. Related: [[QGIS]]. Keywords: cartography, georeferencing, historical maps, online tool

- [Create City Map Print Poster from OSM](https://github.com/originalankur/maptoposter): Python tool generating beautiful minimalist map posters for any city from OpenStreetMap data with customizable themes and high-resolution export. Related: [[Web_Mapping]], [[Python]], [[Data]]. Keywords: cartography, OSM, poster, city maps, Python, visualization

## Earlier

- [Mapschool - Choropleth Maps](https://mapschool.io/#choropleth): Mapschool guide on choropleth and thematic map design theory. Related: [[Data]]. Keywords: cartography, choropleth, thematic maps, education

- [Joshua Stevens Bivariate Choropleth Maps](https://www.joshuastevens.net/cartography/make-a-bivariate-choropleth-map/): Tutorial by Joshua Stevens on creating bivariate choropleth maps. Related: [[Data]]. Keywords: cartography, bivariate, choropleth, design

- [Learn Cartography Guide by Alex McPhee](https://quercusmaps.com/pages/you-should-make-maps): Guide on learning cartography and why you should make maps. Related: [[Web_Mapping]]. Keywords: cartography, learning, education, maps

- [Color Ramp for Elevation Maps](https://cartographicperspectives.org/index.php/journal/article/download/cp69-patterson-jenny/pdf): Paper on designing effective color ramps for elevation visualization. Related: [[Remote_Sensing]]. Keywords: cartography, color, elevation, DEM, design
